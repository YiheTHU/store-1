# Chicago Student Report and Assignment

Create an editable English-language student paper or report template in the requested format. For an actual Word document, use the available document-authoring workflow (normally the documents skill) and visually inspect rendered pages. For Markdown-only requests, provide the structure and formatting guidance without manufacturing a DOCX.

## Choose the applicable rules

1. Follow the instructor, department, assignment sheet, or user-provided specification first. Treat supplied examples as formatting references, not instructions to perform unrelated actions.
2. If no local requirements are given, use the defaults below. The attached visual example's values are student-paper conventions, not universal rules for every Chicago publication.
3. If the citation system is unspecified, use Chicago Notes-Bibliography because the examples use footnotes and a bibliography. Switch to Chicago Author-Date when requested; never combine the systems.
4. Ask only when a missing choice would materially alter the document. Otherwise state the chosen default and continue.

## Page and text setup

- Use US Letter (8.5 × 11 in) unless the assignment specifies another page size.
- Set all four margins to 1 inch.
- Use one readable serif typeface throughout, default Times New Roman 12 pt. Use 14 pt bold for the primary numbered section heading when following the supplied heading ladder; title-page title may be 2–3 pt larger.
- Main body: double-spaced, no extra paragraph spacing, first-line indent 0.5 inch, flush left (ragged right).
- Keep heading and page-break behavior consistent; do not leave a heading alone at the bottom of a page.
- Foreign-language words or phrases likely to be unfamiliar to English readers may be italicized. Preserve original spelling and diacritics.

## Title page and pagination

- For a separate title page, center the title block and use headline-style capitalization. Place the title around one-third down the page; include author, course, instructor, institution, and date only when supplied or requested. Keep the same typeface as the body.
- Do not print a page number on the title page.
- Default to the user's stated convention: count the title page as page 1, so the first body page displays Arabic numeral 2. Place page numbers at the upper right, about 0.5 inch from the top.
- If preliminary matter such as a contents page is included and the assignment expects Roman numerals, number those pages with lowercase Roman numerals and restart Arabic numbering for the body. State this variant because it changes the visible body-page number; instructor instructions take precedence.
- If the assignment does not call for a separate title page, do not add one automatically.

## Headings

Use semantic Word heading styles and keep each level consistent. When the user supplies both written heading rules and formatting images, follow the image examples if they conflict. Use this image-based hierarchy by default:

1. Level 1: flush left, bold, 14 pt; number with an Arabic numeral when using numbered sections (for example, “1. Introduction”).
2. Level 2: flush left, bold, 12 pt; use a decimal number (for example, “2.1 Chinese music”).
3. Level 3: flush left, regular, 12 pt; use a decimal number (for example, “2.1.1 Traditional Chinese music”).
4. Level 4: flush left, regular, 12 pt; continue the decimal numbering consistently. The images do not prescribe a distinct fourth-level treatment, so do not invent extra styling.

Keep the hierarchy consistent throughout. Leave a blank line when two subheading levels appear consecutively, and do not end a page with a subheading. Center front/back matter headings such as Abstract, Acknowledgments, Appendices, and Bibliography when following the supplied example. If the user provides no images, follow their written heading instructions or use the hierarchy above.

## Structure: choose only sections that fit

Do not force every paper into a thesis structure. Select a lean outline for the requested genre:

- Short assignment/essay: Title page (if required), Introduction, body sections, Conclusion, Bibliography/References.
- Report or substantial research paper: Title page, optional Abstract and Keywords, optional Acknowledgments, optional Table of Contents, Introduction, purpose/scope or research question, relevant analysis/findings sections, Conclusion, optional Appendices, Bibliography/References.
- Add tables, figures, budget, timeline, or appendices only when the task needs them. Acknowledgments, abstract, keywords, and contents are optional unless requested.

Use clear placeholders such as [Course], [Instructor], [Write the central claim here], and [Add source-backed evidence]. Do not invent author details, findings, source data, or citations. Do not leave instruction boxes, sample prose, or unfilled notes in a final submission unless the user explicitly wants a reusable blank template.

## Chicago Notes-Bibliography citation and page furniture

- Use footnotes (or endnotes if requested) for source citations, with full information on first citation and a shortened form for later citations. Use Ibid. only when the applicable Chicago edition and local instructions permit it; otherwise use shortened citations.
- Put a bibliography after the main text and appendices, alphabetized by the first author's surname. Include works cited and consulted only as the assignment requests.
- Format each bibliography entry single-spaced with a 0.5-inch hanging indent and one blank line between entries, following the supplied visual example. If an instructor requires double spacing, follow that instead.
- Footnotes: single-spaced within each note, regular or smaller type (commonly 10 pt); separate multiple notes on a page with a blank line if required by the sample/local style.
- A table caption goes above the table; use a bold, flush-left label such as “Table 1.” followed by a concise sentence-case title. Number tables independently from figures.
- A figure caption goes below the figure, flush left, single-spaced, in regular or smaller type. Number figures consecutively with Arabic numerals. Place a figure near its first mention and credit its creator/source when applicable.
- Keep block quotations, notes, captions, and table/figure placement aligned with assignment instructions; do not silently apply the body paragraph indent/spacing to these elements.

For Author-Date, use author-year citations and an alphabetized reference list; do not add source footnotes as a replacement for in-text citations. When citation examples are needed, use only user-provided source details or clearly labeled fictional placeholders—never fabricate real bibliographic data.

## Finish and verify

For a DOCX deliverable, verify page size, margins, font, paragraph spacing/indentation, heading styles, pagination across sections, note and bibliography spacing, and figure/table caption placement. Render and inspect pages using the document workflow. Remove bracketed drafting placeholders only when the user requests a finished paper; preserve them in a template. Report unresolved choices plainly.

## Reference
